# Python Laboratory Assignment

A collection of 10 beginner-friendly Python console tasks.

## Requirements
- Python 3.10 or newer
- No external packages required (Python standard library only).

## Run
```bash
python3 laboratory_assignment.py
```
Choose a task from the menu (1–10), or enter `0` to exit.

## Tasks
1. Grade Converter
2. Playlist Manager
3. Temperature Conversion Table
4. List Comprehensions and Filtering
5. Inventory Management
6. Sorting and Displaying Data
7. Anagram Checker
8. Daily Steps Tracker
9. Word Length Analyzer
10. Online Store Orders System

## Concepts
Conditionals, loops, functions, lists, dictionaries, tuples, list comprehensions, sorting, strings, and exception handling.

## Note
Data entered during a run is stored in memory only and is not saved after the program exits.
